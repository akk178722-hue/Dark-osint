🔍 Основные функции
1. Поиск по номеру телефона
Вводите номер в международном формате (например, +7 922 530 1714). Инструмент определяет:
Страну, флаг, столицу, население, валюту, часовой пояс и форму правления.
Оператора связи, регион и город (на основе встроенной базы операторов).
Технические данные: MCC/MNC, IMSI, MSC, тип сети, статус HLR (активен/неактивен).
Ссылки на мессенджеры (WhatsApp, Viber, Telegram) и соцсети.
Google Dorks для дальнейшего поиска в интернете.
Дополнительные данные через публичное API (геолокация, регион, почтовый индекс).

2. Поиск по IP-адресу
Вводите IPv4 (например, 8.8.8.8). Вывод:
Геолокация (страна, город, регион, координаты, время, погода).
Информация о провайдере, ASN, организации.
Оценка риска (прокси/хостинг/мобильность, процент риска).
Ссылки на сервисы проверки IP (AbuseIPDB, VirusTotal, IPinfo).

3. Поиск по email
Вводите адрес электронной почты. Результат:
Провайдер, возраст домена, записи MX, SPF, DMARC.
Проверка на утечку (симуляция) с указанием источника (например, LinkedIn 2021).
Оценка риска и ссылки на сервисы (HaveIBeenPwned, Dehashed, EmailRep).

4. DDOS-панель
Симулятор атаки на указанный IP или домен. Позволяет:
Запустить и остановить «атаку».
Наблюдать за количеством отправленных пакетов, статусом и логом событий.
Используется для демонстрации и обучения (вредоносные действия не выполняются).

5. Граф связей
Для любого найденного объекта (номер, IP, email) можно построить интерактивный граф, показывающий связи с географией, оператором, провайдером, утечками и т.д. Граф можно сохранить как PNG.
6. Статистика и история
Все запросы сохраняются в localStorage – история с типом и временем.
Ведётся общая статистика по числу запросов каждого типа.
Можно очистить историю или статистику одной кнопкой.

🧠 Как это работает
Данные – встроенная база стран (более 200), операторов, MCC/MNC. Для номеров, которых нет в базе, используется логика определения страны по коду.
Реализм – часть данных симулирована (например, статус HLR, утечки, риск), чтобы показать возможную структуру отчёта без реального обращения к платным API.
API – при поиске номера выполняется запрос к открытому сервису htmlweb.ru для получения дополнительной информации (регион, оператор, координаты). Если API недоступен, отчёт строится на внутренних данных.
Хранение – история и статистика сохраняются в браузере, поэтому данные не теряются после перезагрузки страницы.
Адаптивность – интерфейс оптимизирован для смартфонов: крупные кнопки, минималистичная сетка, скрытие второстепенных элементов на малых экранах.
